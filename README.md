# Profit Analysis – Excel & Power BI

## Project Overview

This project focuses on analyzing business data to understand the key factors influencing **profit** and generate meaningful business insights.

The project was primarily analyzed using **Microsoft Excel**, including data cleaning, exploratory analysis, correlation analysis, and regression analysis. Power BI was used to create interactive visualizations and present the key findings in a clear and user-friendly format.

---

## Project Objectives

* Analyze business data to understand profit performance.
* Identify factors influencing profit.
* Perform data cleaning and preparation.
* Conduct exploratory data analysis.
* Analyze relationships between variables using correlation analysis.
* Perform regression analysis to understand factors affecting profit.
* Create visualizations and dashboards using Power BI.
* Generate actionable business insights.

---

## Dataset

The dataset contains business-related information used to analyze sales, costs, and profit.

The data was cleaned and prepared before performing the analysis.

## Analysis Performed

### Excel Analysis

Microsoft Excel was used for:

* Data cleaning and preparation
* Descriptive analysis
* Exploratory data analysis
* Correlation analysis
* Regression analysis
* Model evaluation using "R² (R-squared)"

### Power BI Visualization

Power BI was used to transform the analyzed data into interactive visualizations and dashboards.

The dashboard helps present:

* Profit performance
* Sales and profit trends
* Relationships between business variables
* Category-wise performance
* Other key business metrics

---

## Regression Analysis

Regression analysis was performed in Excel to understand the relationship between "Profit" and the selected independent variables.

The regression model was evaluated using "R² (R-squared)" to determine how well the selected variables explain variations in profit.

---

## Key Insights

R&D Spend is the most critical factor driving Profit. Marketing Spend contributes but less than R&D.
Administration cost shows very low/insignificant impact. High R&D + Balanced Marketing leads to maximum profit growth.
